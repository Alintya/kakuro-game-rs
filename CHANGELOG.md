# Changelog

## [0.1.0] - 2026-10-13

### Added
- Uniquely solvable puzzle generator: Beginner 6×6, Intermediate 9×9, Expert 12×12, custom 4×4–15×15.
- Pen and pencil entry, live conflict highlighting, undo/redo, play clock.
- Auto-save after every change; restore on launch.
- Share puzzles by code (`<size>-<seed>-<check>`).
- Optional solving aids: run combinations panel, digit-pad dimming.
- System/Light/Dark theme; custom title bar on Windows.
- Portable Windows, Linux (AppImage) and macOS builds published from release tags.
